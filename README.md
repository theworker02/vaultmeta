# vaultmeta

Vault timestamps and meta durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/vaultmeta/

## Install / run

```bash
git clone https://github.com/theworker02/vaultmeta.git
cd vaultmeta
node src/cli.js
node --test
```
